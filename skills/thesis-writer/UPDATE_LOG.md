## 🎯 什么是双工作结构?

双工作结构是知网学位论文的常见模式,特点是:

- **第3章**: 完整的工作1 (引言 + 方法 + 实验 + 小结)
- **第4章**: 完整的工作2 (引言 + 方法 + 实验 + 小结)
- **两个工作**: 相关但独立,各有完整的"方法+实验"闭环

### 典型案例

```
论文题目: 基于深度学习的XX方法研究

第3章: 基础模型A的设计与实现
  - 3.1 引言
  - 3.2 问题定义
  - 3.3 模型A设计
  - 3.4 实验与分析 (工作1的实验)
  - 3.5 小结

第4章: 改进模型B的设计与实现
  - 4.1 引言 (说明基于第3章改进)
  - 4.2 问题定义
  - 4.3 模型B设计
  - 4.4 实验与分析 (工作2的实验 + 与工作1对比)
  - 4.5 小结 (总结两个工作协同效果)
```

## 🚀 如何使用

### 方式1: 自动识别

直接告诉AI你的需求:

```
我需要写一篇论文,包含两个工作:
1. 工作1: [描述]
2. 工作2: [描述]
```

AI会自动识别为双工作结构,使用对应模板。

### 方式2: 明确指定

在阶段2大纲设计时,AI会询问:

```
Q: 你的论文包含几个独立的研究工作?

A. 单一工作
B. 双工作 ← 选择这个
C. 多工作
```

### 方式3: 查看示例

阅读 `EXAMPLE.md` 了解完整的双工作结构使用流程。

## 💡 双工作结构的关键点

### 1. 明确两个工作的关系

在多个位置反复强调:
- **1.3节**: 本文主要工作
- **3.1节**: 工作1引言
- **3.5节**: 工作1小结(为工作2铺垫)
- **4.1节**: 工作2引言(基于工作1)
- **4.5节**: 工作2小结(总结协同)
- **5.1节**: 总结(升华整体贡献)

### 2. 保持结构对称

第3章和第4章的子节结构应该对应:
```
3.1 引言 ↔ 4.1 引言
3.2 问题定义 ↔ 4.2 问题定义
3.3 方法设计 ↔ 4.3 方法设计
3.4 实验分析 ↔ 4.4 实验分析
3.5 小结 ↔ 4.5 小结
```

### 3. 避免内容重复

- 共同基础知识 → 第2章
- 工作1特有内容 → 第3章
- 工作2特有内容 → 第4章

### 4. 体现协同效果

在第4.4.5节专门写"与工作1的对比/联合效果":
- 单独性能对比
- 质量保持验证
- 联合使用效果
- 互补性分析
