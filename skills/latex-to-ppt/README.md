# latex-to-ppt

从 LaTeX 学位论文生成高质量 PPT Markdown，可直接粘贴到 **Gamma / Kimi / Beautiful.ai** 等工具生成演示文稿。

## 使用场景

- 📚 学位论文 → 答辩 PPT
- 📄 期刊/会议论文 → 汇报 Slides
- 🔬 研究报告 → 展示材料

## 快速开始

直接对 AI 说：
> "请用 latex-to-ppt skill，根据 @[thesis.tex] 生成 PPT Markdown"

## 主要特性

- 自动提取论文结构（5章 → 20-30张幻灯片）
- 内置幻灯片模板库（封面、方法、实验、消融、可视化、结论）
- 数字先行原则：所有关键结论带具体数据（如"MSE降低6.7%"）
- 质量检查清单确保内容完整性

## 输出格式

生成 Markdown 文件，包含：
- 幻灯片索引
- 每张幻灯片内容（用 `---` 分隔）
- 图片占位符（标注位置和描述）

## 文件

- `SKILL.md` — 完整 skill 指令
- `EXAMPLE.md` — 基于刘学文论文生成的27张幻灯片示例
